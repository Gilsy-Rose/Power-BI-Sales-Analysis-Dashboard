# Power-BI-Sales-Analysis-Dashboard
Sales Data Analysis and Interactive Dashboard using Microsoft Power BI, Power Query, DAX, and data visualization techniques
This project focuses on analyzing sales data using Microsoft Power BI. The dataset contains 1,000 sales records with information about orders, customers, regions, products, sales, costs, and profits.

The main objective is to clean and transform the dataset, perform DAX calculations, and create interactive visualizations to gain meaningful business insights.
